# 交通信号与信息交互标准索引

## 核验说明

下表依据国家标准全文公开系统和公安标准化信息服务平台于 2026-08-25 核验。标准状态会变化，进入采购、验收或现实道路控制前必须再次查官方平台并阅读全文；本知识库只记录适用主题，不替代合规审查。

## 校园区域相关

GB 5768.8-2018《道路交通标志和标线 第8部分：学校区域》截至核验日现行。GA/T 1215-2025《中小学与幼儿园周边道路交通组织设计与交通设施设置规范》于 2026-05-01 实施并代替 GA/T 1215-2014。校园场景设计应使用现行版，不再以 2014 版作为核心依据。

## 已淘汰版本

GB/T 31418-2015、GB 25280-2010、GB 14886-2006 和 GA/T 1215-2014 已被新版替代，不应作为“现行要求”引用。历史资料可用于版本追溯，但必须标注废止。

## 与 citypulse 的边界

项目 Protocol 2.0 是 Worker 内本地算法 JSON 契约，只输出目标相位和车辆动作；它不是 GB/T 20999-2017 或 GB/T 43229-2023 的实现声明。未经逐条符合性分析、测试和认证，不得写“符合某国家标准”。
